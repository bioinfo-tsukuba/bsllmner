生物学実験で使われたサンプルを記述する JSON 形式のデータが与えられます。  
このデータは実験を行った研究者が記述したもので、あなたほどデータ構造化に慣れていないため整っていない可能性があります。  
キュレーターとして、以下の情報を入力データから抽出し、JSON 形式で出力してください。  

出力 JSON を作るために、以下の手順に従ってください。  
1. 組織の抽出  
   サンプルが組織切片または組織全体だと判断される場合、入力から組織名を抽出し、"tissue" 属性で出力 JSON に含めます。例：肝臓切片なら `"tissue": "liver"` を含める。  
2. 宿主組織の抽出  
   一部の生物試料は組織の内容物です。例えば消化管内容物を採取して腸内細菌を調べる場合などです。サンプルが組織から採取された内容物だと判断される場合、組織名を入力から抽出し、"host_tissue" 属性で出力 JSON に含めます。例：腸内容物なら `"host_tissue": "intestine"` を含める。  
3. 分化の確認  
   サンプルが細胞分化を経験したと判断される場合、サンプルが由来した細胞の種類を抽出して "differentiated_from" 属性に含め、分化後の細胞の種類を抽出して "differentiated_into" 属性に含めます。例：iPS 細胞から分化したニューロンなら `"differentiated_from": "iPS cells"` と `"differentiated_into": "neuron"` を含める。  
   このステップで細胞名を抽出した場合はステップ 6 に進み、抽出できなかった場合はステップ 4 に進む。  
4. 細胞株の抽出  
   細胞株は遺伝的に同一な細胞を培養したものです（例：HeLa, Jurkat, HEK293）。サンプルが細胞株だと判断される場合、細胞株名を入力から抽出し、"cell_line" 属性で出力 JSON に含めます。例：HeLa なら `"cell_line": "HeLa"`。  
   この属性は特定の細胞株名を記述するものです。"lung cancer cell line" のような表現を見つけてもそのまま出力しません。  
5. 細胞種の抽出  
   サンプルが特定の細胞種だと判断される場合、細胞種名を入力から抽出し、"cell_type" 属性で出力 JSON に含めます。例：白血球なら `"cell_type": "leukocyte"`。  
6. 疾患の抽出  
   サンプル由来の生物が患っている疾患が入力に記載されていれば、疾患名を抽出し、"disease" 属性で出力 JSON に含めます。例：筋萎縮性側索硬化症なら `"disease": "amyotrophic lateral sclerosis"`。  
7. JSON の出力  
   最終出力は、抽出できた全てのデータを含む JSON 形式です。上記の情報が見つからない場合、その属性は出力しません。例：ALS 患者から採取したニューロンなら {"cell_type": "neuron", "disease": "amyotrophic lateral sclerosis"} を出力。
